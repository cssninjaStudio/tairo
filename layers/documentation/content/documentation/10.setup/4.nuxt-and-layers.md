title: What is a Nuxt Layer?
---
A nuxt application can grow very fast. You can be multiple developers working on the same application, or you can have multiple applications that share common features.

In order to keep your application maintainable, you need to organize your code. You can use Nuxt layers to organize your code and make it reusable. You can use a layer to create a component library, a set of features, or a set of configuration. You can also use a layer to create a full Nuxt application.

---

Useful resources:

- [Learn more about Layers on nuxt.com](https://nuxt.com/docs/getting-started/layers)

---
title: How Tairo uses Nuxt Layers
---
Tairo is a set of nuxt layers that you can enable depending on your needs. This allows you to create a Nuxt application that is optimized for your needs. Keep only the layers you need, and remove the ones you don't need, so that your application is as light as possible. It also allow us to provide you more features in updates, without having to break your application!


::base-heading{as="h3" weight="light" size="lg" class="not-prose"}
:tairo-toc-anchor{label="Base layers" level="3"}
::


- Shuriken UI: `@shuriken-ui/nuxt`  
  ::base-paragraph{size="sm"}
  This layer provides base components for Tairo, such as buttons, inputs, and cards. It also load tailwindcss, and provides a set of tailwindcss components that you can use to style your application.
  ::

- Tairo Core *(extends from Shuriken UI)*: `layers/tairo`  
  ::base-paragraph{size="sm"}
  This layer is required to use Tairo. It provides features for main content in Tairo, such as tables components, the panels system, the toaster system, and more.
  ::

- Tairo Layout Sidebar: `layers/layout-sidebar`   
  ::base-paragraph{size="sm"}
  This layer provides a sidebar layout, with a sidebar and a content area. It also provides a sidebar menu component.
  ::

- Tairo Layout Collapse: `layers/layout-collapse`  
  ::base-paragraph{size="sm"}
  This layer provides a collapse layout, with a collapse menu and a content area. It also provides a collapse menu component.
  ::

- Documentation: `layers/documentation` 
  ::base-paragraph{size="sm"}
  This layer is an optional layer that you can enable to show the documentation. It uses nuxt-content to load the documentation from the markdown files.
  ::

- Landing: `layers/landing` 
  ::base-paragraph{size="sm"}
  This layer contains everyting related to Tairo's landing page. It mainly to demonstrate that you can, and should, split your application into multiple layers.
  ::

::base-heading{as="h3" weight="light" size="lg" class="not-prose"}
:tairo-toc-anchor{label="App layers" level="3"}
::


- Demo App: `.demo` 
  ::base-paragraph{size="sm"}
  This layer is the demo app. It is used to show you how to use Tairo.
  ::


- Your app: `.app` 
  ::base-paragraph{size="sm"}
  This layer is your app. It is the layer that you will use to create your application.
  ::


::base-heading{as="h3" weight="light" size="lg" class="not-prose"}
:tairo-toc-anchor{label="Enable layers" level="3"}
::

To enable a layer, you need to add it to the `extends` array in your `nuxt.config.js` file. 

In the example below, we load all the layers available in Tairo. *(example from the demo)*

```ts
export default defineNuxtConfig({
  extends: [
    // features layers
    // set them first so they can override the base layers
    '../layers/documentation',
    '../layers/landing',

    // shared layers
    '../layers/tairo', // tairo extends @shuriken-ui/nuxt
    '../layers/tairo-layout-sidebar',
    '../layers/tairo-layout-collapse',
  ],

  // rest of your config ...
})
```
