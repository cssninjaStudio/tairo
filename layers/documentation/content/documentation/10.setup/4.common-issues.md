### `FATAL ERROR: Reached heap limit Allocation failed - JavaScript heap out of memory`

This error is caused by the default memory limit of NodeJS. To fix it, you can increase the memory limit by setting the `NODE_OPTIONS` environment variable:

```bash
NODE_OPTIONS=--max_old_space_size=4096 pnpm dev
```


### `Failed to load resource: the server responded with a status of 504 (Outdated Optimize Dep)`

To fix it, you need to remove `node_modules/.vite` folder and restart the dev server, as Tairo use a pnpm workspace, you can use the following command to remove all `.vite` folders in the workspace:

```bash
find . -maxdepth 4 -name '.vite' -type d -prune -exec rm -rf '{}' +
```
